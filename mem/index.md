# Project Memory

## Core
Calmer institutional aesthetic. Mobile-first. Use `Reveal`, `AnimatedCounter`, `EmptyState`, `FeedSkeleton`, `CoachMark`, `ScrollableTabsList` instead of ad-hoc patterns.
Never use generic spinners or blank "no results" panels — reach for the branded skeleton/empty primitives.
PageTransition wraps Routes in App.tsx — page changes fade+lift automatically.
